# 浏览器插件安装指南

## 目标

把 `extension/` 目录中的 `FOMO EVM 买入监控` 作为未打包扩展加载到 Chrome 或 Edge。插件会在任意 HTTPS 页面显示悬浮窗，用于查看用户配置的自部署后端输出的 EVM 买入事件。

## 安装步骤

1. 打开扩展管理页：

   ```text
   chrome://extensions
   edge://extensions
   ```

2. 开启 `开发者模式`。
3. 点击 `加载已解压的扩展程序`。
4. 选择仓库中的 `extension/` 目录。
5. 修改代码后，需要在扩展管理页点击一次 `重新加载`。
6. 刷新已经打开的网页标签页。

## 配置后端地址

1. 点击浏览器工具栏里的插件图标。
2. 在 `后端 API 地址` 中填写后端入口。
3. 点击 `保存配置`。
4. 浏览器弹出权限确认时，允许插件访问该后端地址。

示例地址：

```text
https://your-monitor.example.com
http://127.0.0.1:8787
```

后端必须实现：

```text
GET /health
GET /api/status
GET /api/events?limit=100
```

## 常见问题

如果悬浮窗显示 `请先在插件弹窗配置后端 API 地址`，先打开插件弹窗保存后端地址。

如果悬浮窗显示 `监控 API 未连接`，先检查：

```text
<后端 API 地址>/health
<后端 API 地址>/api/status
```

如果接口正常但页面无变化，重新加载扩展并刷新网页。

如果关闭了悬浮窗，可以点击浏览器扩展图标，再点 `显示悬浮窗`。
